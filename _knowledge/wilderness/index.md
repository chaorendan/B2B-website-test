# 野外生存与空间决策

这个栏目只做一件事：**把 GIS 的空间思维，用在真实的风险场景里。**

选址、撤离、风险判定、搜救，本质上都是空间问题——哪些地方不能待、多久能走到、哪条路会先断、人可能在哪。这些用等高线、路网、水线和成本栅格能算得比直觉准。

> 边界：本栏目不提供医疗处置、物种识别与野外急救操作。那些内容需要在持证课程中实操，不适合写成网页。

## 方法主线

| 问题 | 对应空间方法 |
| --- | --- |
| 多久能走到 | 服务区分析、成本距离 |
| 哪里不能去 | 风险图层叠加、缓冲区、坡度分级 |
| 走哪条才不断 | 路网连通性与单点失效分析 |
| 人可能在哪 | 视域分析、概率搜索网格 |
